# Қазақстан 1939–1953 — интерактивті тарихи сайт

## Жоба файлдары
- `index.html` — сайттың барлық бөлімдері мен мазмұны
- `style.css` — дизайн және телефон/компьютерге бейімдеу
- `app.js` — хронология, интерактивті карта, тұлғалар, 30 дерек және 5 сұрақтық ойын

## Жобада сақталған оқу материалдары
- 10 негізгі тезис
- 30 тарихи дерек
- 10 тарихи тұлға
- 5 сұрақтан тұратын интерактивті ойын, түсіндірмелерімен
- 5 қосымша оқу тапсырмасы
- 3 тақырыптық видеоға сілтеме
- Хронология, нақты географиялық негіздегі интерактивті карта
- Ғылым, әдебиет және өнер туралы бөлім
- AI-оқытушыға арналған 3 сұрақ-жауап
- Тарихи дереккөздер тізімі

## Сауалнама
Сайттағы «Сауалнама» батырмасы Google Forms сауалнамасын ашады. Қатысушылардың жауаптары Google Forms-та сақталады. Нәтижелерді форманың редакторлық бетінде **Жауаптар → Сводка** бөлімінен көруге болады. Сайтқа ойдан шығарылған статистика енгізілмейді.

## Карта
Карта OpenStreetMap және Leaflet арқылы жүктеледі. Карта плиткаларын көрсету үшін интернет байланысы қажет. Егер карта ашылмаса, бөлімдегі OpenStreetMap сілтемесін пайдалануға болады.

## GitHub Pages-ке жариялау
1. Репозиторийдегі `index.html`, `style.css`, `app.js` файлдарын негізгі (`root`) бумада сақтаңыз.
2. GitHub → **Settings → Pages** бөліміне кіріңіз.
3. **Deploy from a branch**, `main`, `/(root)` таңдаңыз.
4. Сақтап, GitHub Pages берген сайт сілтемесін ашыңыз.

Ескерту: сайттағы үш тақырыптық видео YouTube сілтемелері ретінде ашылады. AI-видео сайтқа енгізілмеген; оны бөлек көрсетуге болады.
